# Proposed stories

Work that has been thought through but not scheduled, and is not yet an issue.

A story belongs here when the *what* is understood well enough to write down but
the *whether* or the *which* is not settled. Common cases:

- the choice between two viable approaches depends on information that does not
  exist yet
- the work is worth doing only if some condition holds, and nobody knows yet
  whether it does
- an investigation produced a finding worth acting on eventually, but acting now
  would be premature
- something was descoped from a delivered story and should not be lost

The point is to stop the analysis being redone from scratch. A proposed story
should leave a reader able to pick it up cold, so alongside the usual goal,
scope and non-goals it should record:

- **the evidence** already gathered, or a pointer to where it lives
- **a recommendation**, if there is one, and what it rests on
- **what would trigger picking it up** — the condition, measurement or decision
  that would settle it, stated concretely enough to recognise when it arrives

Nothing here is a commitment. A proposal that turns out to be wrong, or is
overtaken, should be deleted rather than left to rot.

Moving one out: open an issue, create `doc/plan/{story-name}/story.md` from this
file, and delete it here.
